# Contributing

## Branch naming

- `feature/...` for functionality
- `content/...` for articles, case studies and teaching material
- `fix/...` for corrections
- `chore/...` for maintenance

## Commit style

Use clear, outcome-oriented commits:

- `Add Carnatic music lesson inquiry path`
- `Publish Playwright modernization case study`
- `Improve mobile navigation`
- `Update AI evaluation service copy`

## Publishing rule

No client name, logo, screenshot, document, metric or testimonial may be published unless it is already public or explicit permission has been obtained.
